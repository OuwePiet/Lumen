# VIA watermark release note

This change activates a subtle VIA presentation watermark on NFT media cards.

Release checks:
- transparent vector asset exists;
- overlay component uses no pointer interaction;
- NFT media frame is positioned as the local overlay anchor;
- DeSo read-only NFT loading is unchanged;
- no wallet, signing, transaction or ownership behavior is introduced.

The final VIA logo remains outside this release.
