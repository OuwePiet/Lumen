# VIA Mirror watch

Mirror is tracked as external DeSo ecosystem research, not as VIA product authority.

## VIA boundary

- VIA remains focused on DeSo NFTs, social, communities, creator tools and discovery.
- Mirror trading, leverage and perpetual-market functionality is not copied into VIA.
- Potentially useful DeSo identity, onboarding, navigation and protocol patterns may be evaluated after they are publicly verifiable.
- External launch claims, token economics and roadmap promises are research inputs only; they do not change VIA implementation without separate verification.
- viadeso.online remains the VIA product baseline.

## Review rule

When Mirror exposes new public product or protocol behavior, compare it with VIA for reusable UX or DeSo integration ideas. Record rejected or deferred ideas in the stock/Phase 3 track so nothing disappears silently.
