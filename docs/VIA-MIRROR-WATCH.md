# VIA Mirror watch

Mirror is tracked as external DeSo ecosystem research, not as VIA product authority.

- VIA remains focused on DeSo NFTs, social, communities, creator tools and discovery.
- Trading, leverage and perpetual-market functionality are not copied into VIA.
- Useful identity, onboarding, navigation or protocol patterns may be evaluated only after public verification.
- External token economics and roadmap claims are research inputs, not VIA implementation requirements.
- viadeso.online remains the VIA product baseline.

Rejected or deferred ideas belong in the stock/Phase 3 track so nothing disappears silently.
