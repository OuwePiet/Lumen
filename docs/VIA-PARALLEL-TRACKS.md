# VIA Parallel Build Tracks

VIA now has many valid product directions. The solution is not to expose dozens of half-built buttons at once, but to develop several tracks in parallel behind a clear visitor-first structure.

## Principle

Build many tracks in parallel, release only what is understandable and useful.

Each track can be in one of four states:

- **Live** — tested and available to visitors.
- **Foundation** — route/UI exists, but deeper functionality is intentionally limited.
- **Research** — requirements, providers, legal/security or protocol questions are still being verified.
- **Later** — valuable, but deliberately not taking priority now.

## Track map

### Social
- Feed choice: Following / Recent / Discovery.
- Posts, replies, quote, repost, likes/diamonds.
- Search and creator discovery.
- Communities.
- Messages after DeSo messaging/security verification.

### Creator
- VIA Studio.
- Drafts and media workflows.
- Creator pages and collections.
- NFT minting/management with explicit blockchain signing.
- Creator visibility through organic discovery and eligible Repeat.

### NFT
- Collection browser and detail pages.
- Current owner / copies / sale status.
- Mint foundation.
- Later buy, sell, auction, claim, transfer and unlockable content where DeSo support and signing flows are verified.

### Read
- Daily News as a separate full-page environment.
- Read & Stories for creator/community long-form work.
- Learn / Knowledge for explainers and guides.

### Listen & Talk
- World Radio.
- VIA LIVE.
- Replay only with explicit recording consent and a verified implementation.
- Messaging as a separate security-gated track.

### Discover
- World Discovery.
- Around the World.
- New Voices.
- NFT Window.
- Surprise Me.
- Future creator/event discovery without pretending to know private location data.

### Play
- World Quest.
- Daily Grid.
- Alphabet Relay.
- VIA NEO PONG.
- VIA Points remain non-monetary and non-transferable.

### Community
- Communities by shared interest.
- Events.
- Idea Box with visible lifecycle.
- Visitor feedback feeding research and product decisions.

### Personal
- My VIA as the visitor-controlled starting environment.
- Favourites/saved items where appropriate.
- Clear preference controls and reset.
- No hidden sensitive-interest profiling.

### Commercial sustainability
- VIA Spotlight: clearly Sponsored self-service promotion.
- VIA Repeat: eligible creator/community resurfacing only.
- Organic ranking stays separate from paid visibility.
- EUR / USD / Bitcoin for advertising; no DESO advertising payment.

### Safety & trust
- Seed phrase/private keys never collected by VIA.
- Explicit wallet signing for blockchain actions.
- Account/session security distinguished from blockchain authority.
- Block/report/spam controls as social features mature.
- Privacy by default and data minimisation.
- Accessibility across all tracks.

### Platform reliability
- DeSo node resilience/fallback where safe.
- Media health and clear unavailable states.
- Monitoring and deployment checks.
- No unsupported 'hack-proof' or absolute reliability claims.

## Release discipline

A new track should only become visible in primary navigation when at least one meaningful visitor action works. Foundations may exist behind direct routes while still in development.

Do not let commercial tracks dominate the homepage. Do not let News take over the homepage. Do not let NFTs take over every visitor journey.

## Current priority lanes

1. **Visitor core** — My VIA, feed choice, navigation, accessibility.
2. **Community** — Communities, Events, Idea Box feedback/status.
3. **Reading** — Daily News source integration, then Read & Stories.
4. **Creator/NFT** — Studio, minting and collection depth.
5. **Discovery/entertainment** — Radio, LIVE, Quest, global discovery.
6. **Commercial** — Spotlight/Repeat foundations, payments only after full review.
7. **Security-gated** — Messages, real payments, recording, sensitive account actions.

Parallel work is encouraged, but every merge must leave VIA understandable, honest about what is live, and consistent with viadeso.online as the baseline.
