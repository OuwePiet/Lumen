# VIA Social — deferred views

viadeso.online remains the product baseline. DeSo communication belongs on the dedicated Social surface, not on Home.

## Welcome

- Historical VIA stock includes a Welcome view intended to help visitors discover constructive introductions and onboarding-oriented public posts.
- It is not active yet because VIA has not defined an authoritative, abuse-resistant rule for what qualifies as a welcome post.
- Do not present this as a live DeSo feed until the source and ranking rules are explicit and testable.

## First Posts

- Historical VIA stock includes a First Posts view intended to surface genuinely new public creators/posts.
- It is not active yet because VIA has not verified a reliable source-of-truth for a creator's actual first post that is suitable for bounded public feed retrieval.
- Do not infer first-post status from a small recent-post sample.

## Release rule

These ideas remain in stock and may move into the active Social build only after their DeSo read contract, ranking semantics, abuse handling and empty/error states are verified. No wallet authority or write action is required for the intended read-only versions.
