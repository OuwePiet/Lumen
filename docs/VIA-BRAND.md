# VIA brand rule

## Canonical identity

- Product name: **VIA**
- Public domain: **viadeso.online**
- Current product copy, metadata, UI labels, documentation and new code must use **VIA**.

## Historical names

`Lumen` and `VERO` are historical project/source names only. They may remain in Git history or archived source material when needed for traceability, but must not be presented as the current product name.

## Infrastructure exception

Legacy GitHub/Vercel resource names may temporarily retain `Lumen` while they are still technically linked to the working deployment. Do not rename or recreate infrastructure merely for cosmetics if that risks breaking VIA. When infrastructure is migrated, preserve redirects and deployment continuity.

## Review rule

Any new user-facing occurrence of `Lumen` or `VERO` is a release blocker unless it is explicitly marked as historical context.
