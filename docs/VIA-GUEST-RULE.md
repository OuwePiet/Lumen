# VIA Guest Rule

VIA's public entrance stays open without registration, but an open entrance is not anonymous participation.

- A guest can move through public VIA pages and consume public content.
- A guest cannot create or change public/community/DeSo state.
- Participation requires the verified DeSo route.
- DeSo's own funding/balance rules remain DeSo rules and may provide useful bot friction.
- A funded or logged-in account is not automatically trusted.
- VIA still protects write surfaces against spam, bots, scams, impersonation and malicious links.
- Financial and blockchain actions require stronger explicit transaction controls.

This rule applies consistently to Social, Show Your Stuff, First Maker Space, Communities, Messages and future participatory modules.
