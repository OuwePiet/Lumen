# VIA Entry Flow

## 1. Walk in

No registration wall for public VIA discovery. A visitor can first decide whether the people, work and communities are interesting.

## 2. Look around

Public navigation, search, reading, watching and listening remain available. This is a view-only relationship with VIA/DeSo/community state.

## 3. Want to take part

VIA opens the verified DeSo login/account path. VIA does not create a parallel social identity for this purpose.

## 4. DeSo requirements

If the current DeSo flow requires the account to obtain/fund $DESO before a particular action becomes available, VIA explains the verified requirement and opens the appropriate DeSo route. The requirement belongs to DeSo; VIA does not turn it into its own entrance fee.

## 5. Participate

After valid DeSo authority is established, VIA may enable implemented social/community write actions. Behaviour controls still apply because login or funding does not equal trust.

## 6. Sensitive action

NFT, payment and other blockchain actions require the additional transaction preflight, cost disclosure, explicit consent, signing and verification flow.

**Walk in → discover → DeSo → participate → stronger control for sensitive actions.**
