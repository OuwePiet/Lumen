# VIA Free Base

Free access is the baseline for ordinary VIA use.

## Principle

VIA should contribute a lot of enjoyment with a small, efficient technical footprint and earn only a modest sustainable amount from optional paid extras and services.

Voluntary contributions may exist, but VIA does not depend on donations as a business model.

## Ordinary use stays free

Reading, listening, discovering, talking, playing, browsing and ordinary creator/community participation should not require payment first.

## Cost discipline

VIA should keep recurring infrastructure costs low and avoid architecture that later forces high subscriptions or broad paywalls.

By default VIA does not require:

- its own DeSo node;
- a validator;
- its own blockchain;
- a heavy indexing cluster;
- costly always-on media streaming infrastructure;
- expensive background services when a lighter public, serverless, decentralized or external option is suitable.

Features that inherently introduce large recurring infrastructure costs belong in later review before implementation.

## Sustainable income

VIA can earn from clear optional value, for example Spotlight, Repeat, storage services and selected creator/NFT extras. Prices should be transparent and proportionate to the actual extra service.

Free access must not be weakened merely to manufacture a reason to pay.

## Storage exception

Storage has real external costs. A free platform experience therefore does not mean unlimited free storage. Storage rules and prices are handled in the separate VIA Storage track. NFT minting has its own visible free-file threshold and paid-storage path for larger files.
