# VIA launch and growth stock

This note records useful growth ideas without interrupting the active VIA product build. viadeso.online remains the product baseline.

## Adopt as direction

- Start with the existing DeSo/NFT/creator community rather than marketing to everyone at once.
- Make onboarding understandable for non-technical visitors; public reading and collection exploration should work before wallet authority is required.
- Build in public with factual progress updates rather than hype or unverified superiority claims.
- Make VIA content and minted items easy to share externally so creators can bring audiences back to VIA.
- Grow internationally; English remains a suitable default while VIA's multilingual track develops.
- Treat the first active creators, collectors and community participants as the initial network nucleus.

## Later, when public beta is stable

- Prepare a coordinated public launch and directory submissions.
- Evaluate launch communities and relevant app directories at that time using current requirements rather than hard-coding today's third-party platforms into VIA.
- Create an onboarding/launch checklist covering reliability, mobile usability, accessibility, moderation, sharing and support before broad promotion.

## Not adopted as-is

- No VIA token or airdrop is introduced merely as a growth mechanism. VIA is built around DeSo and $DESO.
- Invite-only access is not the default because public NFT/social discovery is part of VIA's value; controlled beta access may still be useful for write-capability testing.
- No paid or special verification status is granted merely for promotional cooperation.
- No promise such as censorship-proof, algorithm-free, copy-proof or guaranteed creator income is used without a precise technical basis.
- Passkeys/email-style onboarding may be evaluated, but convenience must never become silent signing or storage of seed/private-key material.

## Growth principle

VIA growth should come from product utility and network effects: creators publish or display work, collectors discover it, social activity creates context, and sharing brings new visitors back into the same DeSo-based environment.
