# VIA watermark

The VIA collection watermark is a presentation overlay only.

- It is not written into or used to alter the creator's NFT media.
- It does not change DeSo NFT ownership, metadata or on-chain content.
- It must remain subtle, non-interactive and secondary to the artwork.
- It uses `pointer-events: none` and is hidden from assistive technology.
- The media container anchors the overlay locally so it cannot escape the NFT card.

The current vector asset is a technically safe VIA placeholder/wordmark asset. Final VIA logo artwork remains a separate brand track and should only replace it after visual approval.
