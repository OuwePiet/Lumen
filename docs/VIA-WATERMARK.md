# VIA watermark

The VIA collection watermark is a presentation overlay only.

- It does not alter the creator's NFT media.
- It does not change DeSo ownership, metadata or on-chain content.
- It is subtle, non-interactive and secondary to the artwork.
- The overlay uses `pointer-events: none` and is hidden from assistive technology.
- The NFT media frame anchors the overlay locally.

The current vector is a technically safe VIA wordmark asset. Final VIA logo artwork remains a separate visual track and should replace it only after visual approval.
