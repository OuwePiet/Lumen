# VIA page and button map

This document is the fixed placement map for VIA. It exists to prevent duplicate buttons, duplicated navigation and page-specific actions appearing in the wrong place.

## Global rule

The homepage and global VIA shell are the visual quality baseline for the whole product: premium dark layout, calm muted green accents, readable typography, balanced spacing, no duplicated buttons, and no technical explanation blocks competing with the user's main task.

The global main navigation is:

- Home
- Social
- Discover
- NFTs
- Market
- Studio
- Live
- Communities
- My VIA

Global/account-level controls belong in the site shell or account menu rather than being repeated on every page:

- Search members
- Language (English default)
- Public Entrance
- DeSo Login
- Buy $DESO
- Visitors status
- Avatar + username menu
- Notifications
- Messages when the secure DeSo messaging flow is released
- Wallet
- Settings
- Saved
- Switch/Add account
- Logout

World Radio remains globally available. World clocks, $DESO value and Your $DESO belong to the homepage/footer information layer, not duplicated as page actions.

## Home

Home is the premium entry page and visual benchmark.

Visible homepage functions:
- Main VIA navigation
- Search members
- Language
- Public Entrance with compact explanation
- DeSo Login
- Buy $DESO
- Visitors status
- Avatar + username
- Explore NFTs
- Join the Community
- Create a Post
- Go Live
- Featured on VIA
- Sponsor VIA
- Best Performer
- Creator Country
- World clocks
- $DESO Value
- Your $DESO
- DeSo is the Key

Do not add duplicate Profile or Wallet main buttons here because My VIA and the avatar/account menu already provide those routes.

## Social

Purpose: real DeSo social feed and participation.

Primary controls:
- Feed selector: Following / Hot / New / Explore
- Create Post
- Reply
- Like / Unlike
- Repost
- Quote
- Diamond
- Follow / Unfollow
- Emoji reaction only when its DeSo write path is verified
- Save
- Edit own post
- Poll vote

Post actions stay directly under the post they affect. Technical capability notes do not belong in the main reading flow.

## Notifications

Purpose: notification feed that stays visible while the user changes personal filters.

Controls:
- Notification filter/settings button
- Diamond filters
- Mention filters
- Reply/comment filters
- Follow/profile filters
- Repost filters
- Other verified DeSo notification categories

The personal filter/settings layer opens inside or over the notification page; it is not a separate navigation destination.

## Messages

Purpose: private/group messaging, separate from the Social feed.

Do not expose this as a released main route until the secure DeSo access-group messaging encryption/decryption/session flow is complete.

When released, the page contains:
- Conversations
- New message
- Group conversation where supported
- Reply
- Forward where appropriate
- Emoji/reaction where supported
- Relevant DeSo identity/account controls

## Discover

Purpose: discover people and content, not a second home page and not a wall of creator-category cards.

Primary controls:
- People
- Content
- People to Follow
- Ranking Creators / Best Performers
- Search creators/members
- Categories
- Surprise

Secondary discovery routes may include art, photography, music/audio, film/video, NFTs, museums/heritage, writing/stories and world discovery, but these should live behind category/filter navigation rather than all being equally prominent.

## Saved / Bookmarks

Purpose: saved posts/content.

Primary controls:
- Saved Posts
- Remove bookmark
- Normal post actions on each saved post

Do not invent a separate content format for bookmarks.

## My VIA

Purpose: personal hub.

Primary sections:
- Profile
- Wallet
- Saved
- Drafts
- Settings
- Creator shortcuts

Profile contains:
- Cover
- Avatar
- Username
- Verification/account badge where genuinely supported
- Followers / Following
- Days on DeSo where available
- Country when explicitly provided by reliable profile/metadata
- Bio
- Interests/hashtags
- Own posts/NFTs/activity

Do not repeat Read, Listen, Discover, Talk, Create and Play as six large navigation cards if those functions already have their own global destinations.

## Wallet

Purpose: DeSo wallet/account finance surface.

Primary controls:
- Balance
- Public key + Copy
- View Transactions
- Send $DESO
- Buy $DESO
- Creator Coins
- Buy Creator Coins
- Coins Bought
- Coins Received
- Per-creator overflow actions

Wallet-specific actions stay here and are not scattered across unrelated pages.

## NFTs / Collection

Purpose: browse a creator's DeSo NFTs.

Top area:
- Creator search
- Avatar/photo + username only
- Owns
- For Sale
- Media/filter controls
- Sort controls

Do not show the full creator profile on the NFT collection page.

NFT card/detail actions stay with the NFT:
- Open Detail
- Save
- Share / Copy Link
- Owners / copies
- Bid
- Buy Now
- Update Price when owner
- Accept Bid when owner
- Transfer
- Accept Transfer
- Burn
- History
- Unlockable status where applicable

The dedicated metallic VIA leaf mark is the NFT watermark only.

## Market

Purpose: account market activity.

Primary tabs only:
- Received Bids
- My Bids
- Sales
- Transfers

The signed-in account supplies the active DeSo public key automatically. Public account inspection may expose an account selector where needed, but the raw public key must not dominate the interface.

## Studio

Purpose: create, prepare and mint.

Studio opens with four primary choices:
- Create a Post
- Mint an NFT
- Media Workspace
- Drafts

Create a Post contains only post composition controls and the guarded DeSo submit flow.

Mint an NFT contains:
- NFT post hash/content reference as required
- Copies
- Creator royalty
- Coin royalty
- Offer for Sale
- Buy Now
- Unlockable
- Storage/media choices
- Mint cost/preflight
- Review & Mint in DeSo

Safety and transaction boundaries remain enforced but should not appear as repeated large explanation panels.

## VIA Live

Purpose: live community media.

Primary structure:
- Live
- Replay
- How it works
- Community Room

When supported by an authorized live service:
- Listen
- Speak
- Microphone
- Optional Camera
- Record
- Publish

Media Health / Diagnostics is secondary and belongs behind Status/Diagnostics or More.

## Communities

Purpose: discover/open communities and use real community actions when supported.

Primary category choices:
- Art & Photography
- Music
- DeSo & Builders
- NFT & Collecting
- Games & Quest
- Open Community

Inside a community, show only supported actions such as Join/Leave, Post, Mute, Block/Report, visibility/membership and moderation when those paths are verified.

## VIA · THE DESO READ · THE WORLD NEWS

Existing `/news` is the base route.

Presentation:
- VIA · THE DESO READ
- THE WORLD NEWS

Sections:
- World
- Technology
- DeSo & Crypto
- Art & Culture
- Music
- Science

Use concise summaries with clear source attribution and links to original publications. Do not duplicate the global navigation inside the page.

## More / Settings

Secondary or lower-frequency controls belong here rather than taking permanent homepage/nav space:
- Theme
- Feed options
- Location preference
- Notification preferences
- Creator-coin notification thresholds
- Language preferences
- Help
- Diagnostics
- Admin-only tools
- Authenticator/security controls

## DeSo integration rule

Visual cleanup must never remove real protocol functionality. Preserve the verified DeSo flows already built into VIA, including Identity, post/reply, Like/Unlike, Follow/Unfollow, Repost/Quote, Diamonds, poll voting, NFT mint, bids, accept/withdraw bid, sales/transfers, transfer/accept transfer, burn, profile/account reads and guarded transaction approval boundaries.

No control should pretend to be live if its secure/native DeSo path is not yet verified.

## VIA-specific layer

Keep VIA's own identity and product additions where they logically belong:
- Premium globe homepage
- World Radio
- World Quest
- VIA Live
- Featured on VIA
- Sponsor space
- Visitors status
- World clocks
- Creator Country
- Best Performer
- Show Your Stuff
- International discovery
- Saved
- VIA NFT watermark

These additions must complement DeSo rather than duplicate native DeSo functions.
