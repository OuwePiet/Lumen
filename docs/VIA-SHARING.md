# VIA Sharing

VIA games are designed to be easy to share worldwide while keeping visitor control.

- Sharing is always voluntary; VIA never posts automatically for a visitor.
- Shared text and links identify VIA and use `viadeso.online`.
- The native device share sheet is used when available; otherwise VIA copies the share text and link.
- Sharing does not require a wallet, DeSo transaction, payment, account, tracking profile or paid infrastructure.
- Local game scores remain local unless a future separate, explicitly approved online leaderboard is built.
- A shared score or screenshot is never authoritative proof for a Diamond Shower or other on-chain reward.
- VIA should prefer one recognizable Share VIA interaction across games and other suitable public experiences.
