# VIA World Discovery

## Idea

VIA should not only be a place where people publish content. It can help people discover what is happening across the DeSo social graph and, later, across VIA's optional world services such as World Radio.

The working name is **VIA World Discovery**.

## Why it fits VIA

DeSo provides portable profiles, posts, follows, social engagement, tipping and NFT activity. VIA can build a discovery experience on top of those open signals without claiming ownership of the underlying identity or content.

World Discovery is intended to connect three VIA strengths:

1. social discovery;
2. creator and NFT discovery;
3. optional worldwide content such as radio.

## First safe version

The first version should be read-only and inexpensive:

- **Around the World** — browse public DeSo activity by language or region when reliable metadata is available;
- **New Voices** — surface creators beyond only the largest accounts;
- **NFT Window** — rotating discovery of DeSo NFT creators and collections;
- **Radio Nearby / Radio Around the World** — link into VIA World Radio by country, language or genre;
- **Surprise Me** — one optional discovery action that deliberately takes the user outside their normal feed;
- **Following / Recent / Discovery** — clearly separate personal feed choices from VIA discovery ranking.

## Fairness rules

Discovery must not silently become pay-to-win.

- Organic results and paid promotion must be visibly different.
- Sponsored placement must be labelled.
- A creator must not need to pay to be discoverable.
- Ranking signals should be documented before production use.
- Avoid using sensitive personal data for ranking.
- Avoid pretending language or geographic inference is certain when metadata is missing.
- Do not make verification, popularity or quality claims without an authoritative source.

## Possible VIA revenue

World Discovery can support small, transparent revenue without charging for ordinary browsing:

- clearly labelled **Featured Creator** slots;
- clearly labelled **Featured NFT Collection** slots;
- clearly labelled **Sponsored Station** placements in World Radio;
- voluntary DeSo tips/diamonds/support for VIA;
- later, transparent marketplace/service fees where VIA actually provides a paid transaction service.

Paid placement never buys a verification badge or an organic ranking label.

## Cost control

- Prefer DeSo public/on-chain data already needed by VIA.
- Cache only non-sensitive discovery results for short periods.
- Bound profile/NFT enrichment requests.
- Lazy-load radio and media.
- Do not run expensive global scans on every page load.
- Start with deterministic sections rather than AI ranking.

## Privacy and security

World Discovery is read-only in the first phase. It must not require a seed phrase, private key or signing secret. Any future follow, diamond, purchase or other on-chain action remains a separate explicit signed action.

## Later possibilities

Only after the basic discovery experience is reliable:

- user-controlled interests;
- multilingual discovery;
- local/regional trending views based on trustworthy metadata;
- event/community discovery;
- creator-curated radio stations or playlists where rights and source terms permit it;
- transparent recommendation explanations such as “shown because you follow …”.

## Status

**Adopted as a VIA concept.** Build the read-only foundation before adding monetized ranking or transaction actions.
