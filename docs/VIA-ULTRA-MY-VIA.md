# VIA Ultra — My VIA

My VIA should use the same restrained visual language as the Social feed and collection surface: near-black layers, muted VIA green, thin borders, controlled 10–14px corners, transparent actions and calm 200ms interaction states. Large pill controls and bright green accents are avoided except where a compact status badge genuinely benefits from them.

This visual pass must not change My VIA's visitor-controlled behavior, local save semantics, routes or privacy boundary.
