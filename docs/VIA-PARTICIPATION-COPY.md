# VIA Participation Copy

Use short, non-technical wording at the public entrance.

## Guest

**Look around freely.**

You can explore VIA without logging in. Public pages, creators, posts, music, culture and discovery stay open to visitors.

## Participation

**Want to take part? Continue through DeSo.**

Posting and other public participation use the controlled DeSo route. VIA does not create a second participation account beside DeSo.

## Funding

If DeSo requires funding or a $DESO balance for the action, show the verified current DeSo requirement at that point. Do not advertise a fixed VIA entry payment.

## Safety

A DeSo login lets an account participate where the feature is enabled; it is not a VIA guarantee that the account is trustworthy.

## Sensitive actions

Before an NFT, payment or blockchain action, VIA shows the action and applicable costs and requires explicit consent and signing.
