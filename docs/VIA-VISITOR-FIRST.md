# VIA Visitor-First Foundation

VIA is not intended to become "another feed with NFTs". The platform should give visitors useful, enjoyable reasons to return even when they do not want to post, buy or sell anything.

Core principle: **VIA revolves around the visitor, not around one mandatory feed.**

## 1. My VIA

A personal starting environment where a visitor can choose what VIA opens with and what matters to them.

Possible controls:
- Following / Recent / Discovery rather than one compulsory ranking.
- Preferred VIA areas such as Daily News, World Radio, VIA LIVE, NFTs, games and creator content.
- Saved items and favourites where technically appropriate.
- Clear reset and preference controls; avoid hidden lock-in.

Personalisation should be understandable and privacy-conscious. Do not infer sensitive interests or location without an explicit, legitimate user choice.

## 2. Messages

Private communication belongs in VIA, but it must not be presented as private or encrypted until the actual DeSo-compatible messaging mechanism and its security properties are verified.

Foundation requirements:
- clear sender/recipient identity;
- block/report controls;
- spam protection;
- no seed phrase/private-key collection by VIA;
- no misleading encryption claims.

## 3. Communities

Dedicated spaces for shared interests rather than forcing every conversation into the global feed.

Examples: art, music, photography, DeSo, collecting, local/community initiatives and games.

Community controls should include understandable membership/visibility rules, moderation tools and the ability for visitors to leave/mute a community.

## 4. Read & Stories

A calm long-form area for articles, stories, serials, creator writing and reading. This is separate from Daily News: News is sourced current information; Read is creator/community long-form work.

Possible later features:
- chapters/series;
- reading list;
- creator attribution;
- optional NFT relationship for creator-owned editions, without making NFT ownership mandatory for ordinary reading.

## 5. Creator Tools

VIA Studio remains the creator work area. Expand carefully around real creator needs: drafts, media, publication, NFT creation, visibility, audience feedback and transparent creator earnings where supported.

Small/new creators should not be disadvantaged merely because they have low follower counts.

## 6. Events

A separate event/discovery layer for community sessions, VIA LIVE sessions, releases, exhibitions, music and other public creator/community events.

Do not infer a user's location. Location-based discovery must use explicit user selection or appropriate public event metadata.

## 7. Accessibility

Accessibility is a platform requirement, not a separate premium feature. Continue keyboard support, readable contrast, meaningful labels, responsive layouts and reduced-motion-friendly behaviour. Avoid autoplay and interaction patterns that trap visitors.

## 8. Learn / Knowledge

A later knowledge environment can collect explainers and learning material around DeSo, NFTs, creator tools, art, technology and VIA itself. It should prioritise understandable explanations over jargon and distinguish educational information from financial promotion.

## Visitor modes

VIA should support several legitimate ways to visit:

- **Read** — Daily News, stories and knowledge.
- **Listen** — World Radio and VIA LIVE.
- **Discover** — creators, art, NFTs and the wider world.
- **Talk** — posts, communities and messages.
- **Create** — Studio, media and creator/NFT tools.
- **Play** — World Quest and casual games.

No visitor should need to participate in every mode.

## Organic, Repeat and Sponsored

Keep three visibility systems distinct:

1. Organic discovery/feed placement.
2. VIA Repeat for eligible genuine creator/community content.
3. VIA Spotlight for clearly labelled Sponsored promotion and business advertising.

Payment must never silently buy organic reputation or hidden ranking advantage.

## Build order

Implement in small reviewed steps rather than adding empty buttons everywhere:

1. My VIA foundation and visitor-controlled entry choices.
2. Communities foundation.
3. Read & Stories foundation.
4. Events discovery foundation.
5. Messaging only after current DeSo-compatible messaging/security research.
6. Learn/Knowledge and deeper creator tooling after the earlier areas are stable.

Any feature that requires unverified security, payments, private data or blockchain signing stays non-live until reviewed and tested.
