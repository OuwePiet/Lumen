# VIA Access Matrix

| Surface / action | Guest | DeSo authenticated | Additional boundary |
| --- | --- | --- | --- |
| Public Home / Discover navigation | Yes | Yes | None |
| Public creator/profile/NFT reading | Yes | Yes | Read-only APIs |
| Public posts reading | Yes | Yes | Read-only APIs |
| World Radio / public media playback | Yes | Yes | User starts playback; external media untrusted |
| Browser-local Saved / local draft | Yes, when clearly local | Yes | Must not imply public participation |
| Post / reply / quote / repost | No | May be enabled after verified implementation | Explicit user action + DeSo authority |
| Follow / like / Diamond | No | May be enabled after verified implementation | Explicit user action + DeSo authority |
| Public upload / Show Your Stuff submission | No | May be enabled after verified implementation | Abuse/media/link controls |
| First Maker Space / creator claim | No | May be enabled after verified implementation | Controlled DeSo authority + eligibility/abuse checks |
| Messages | No | May be enabled after verified implementation | DeSo authority + spam/abuse controls |
| Mint / bid / buy / sell / transfer / burn / price change | No | Not from login alone | Preflight + costs + consent + signing + verification |
| VIA paid storage/service | No anonymous checkout | May be offered when payment flow is verified | Clear service/provider/network costs + payment verification |

A DeSo login is an access prerequisite for participation, not a VIA trust or verification badge.
